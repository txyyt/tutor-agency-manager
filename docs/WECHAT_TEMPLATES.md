# 微信填写与发布模板

系统内置模板以本文件为准。微信、电话均必填。大学生按指定订单报名，不填写可授课区域。

## 家长需求模板

```text
【家教需求登记】

1. 家长称呼：
2. 微信：
3. 电话：

【孩子及辅导需求】
4. 孩子年级：
5. 辅导科目：
6. 目前学习情况：
   （例如：基础薄弱、成绩中等、希望提高解题能力）
7. 辅导目标：
   （例如：巩固基础、作业辅导、考试复习）

【上课安排】
8. 上课方式：线下 / 线上
9. 上课区域及地点：
   （线下先填写小区或附近地标，无需填写门牌号；线上填写“线上”）
10. 每周可上课的日期和时间：
    （例如：周二、周四 19:00—21:00）
11. 每周上课次数：
12. 每次上课时长：
13. 预计开始时间：

【薪资及老师要求】
14. 薪资：____元/小时
    是否可以协商：是 / 否
15. 老师性别要求：不限 / 男 / 女
16. 对老师的其他要求：
    （例如：专业、教学经验、擅长科目等）

17. 其他备注（选填）：

请按一份独立家教需求填写一份表。
如需分别聘请不同老师，请分别填写。
```

## 大学生报名模板

```text
【大学生家教报名】

1. 报名订单编号：
2. 姓名：
3. 性别：
4. 微信：
5. 电话：

【个人情况】
6. 就读学校：
7. 专业：
8. 当前年级：
   （例如：大二、研一）

【针对本订单的教学能力】
9. 可辅导的科目及年级：
10. 相关成绩或能力说明（选填）：
    （请注明考试名称、年份、分数及满分）
11. 家教或其他教学经验：
    （请说明学生年级、科目、教学时长等；没有经验可填写“暂无”）
12. 针对本订单的优势及辅导思路：

【时间及薪资】
13. 每周可上课的日期和时间：
14. 最早可开始时间：
15. 是否接受订单中的薪资：是 / 否
    如不接受，期望薪资：____元/小时
16. 是否可以按安排参加试课：是 / 否
    如有时间限制，请说明：

17. 其他备注（选填）：
18. 简历附件（选填，可附 PDF 或图片）：

请针对本订单填写。
如报名多个订单，请分别提交，每份注明订单编号。
请如实填写资料和教学经历。
```

## 群内招募模板

只使用以下允许发布字段，不将内部备注和其他自由文本整体拼接到群内文字。

```text
【家教招募｜{订单编号}】
年级：{年级}
科目：{科目}
方式：{线上/线下}
区域：{用于发布的大致区域，线上显示“线上”}
时间：{用于发布的上课时间}
频次：每周{次数}次，每次{时长}小时
开始时间：{预计开始时间或“协商”}
薪资：{薪资}元/小时（{可协商/不可协商}）
性别要求：{不限/男/女}
其他要求：{专门填写的公开老师要求，没有则“无”}

有意向请联系中介，注明订单编号并提交报名模板。
```

多个订单用空行和 `——————————` 分隔。不包含家长称呼、微信、电话、孩子姓名、详细地址、内部备注、费用收款信息。

## 家长候选简历摘要

勾选本单候选报名，生成摘要，按报名编号区分同名老师。附件另行下载，手动发送家长。

```text
【{订单编号}｜候选老师 {报名编号}】
姓名：{姓名}
性别：{性别}
学校：{学校}
专业：{专业}
年级：{老师年级}
可辅导科目及年级：{教学范围}
成绩与能力：{能力说明或“未填写”}
教学经验：{教学经验}
优势与辅导思路：{辅导思路}
可上课时间：{空闲时间}
最早开始：{开始时间或“协商”}
薪资：{接受订单薪资/期望薪资}
试课安排：{是否可试课及时间限制}
```

默认不含老师微信、电话、费用、内部备注。生成摘要或下载不自动标记已推荐；实际发送后手动批量标记。

## 安排试课前的费用告知

```text
【{订单编号}｜费用说明】
本单中介费：{金额}元。
试课前保证金：{金额}元。
上述费用均由报名老师支付。
试课成功并确认正式合作后，保证金抵扣中介费，补齐剩余费用。
试课未通过、老师主动退出或家长取消订单，退回保证金。
双方直接确认合作、跳过试课时，收取中介费；已交保证金同样抵扣。
```

金额按具体报名填写。复制告知不等于登记实际收款或退款。
