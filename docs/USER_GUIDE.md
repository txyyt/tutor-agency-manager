# 使用手册（USER_GUIDE）

家教中介内部管理系统 · 本机Web应用。面向中介操作员（无需账号，本机直接使用）。

## 1. 启动与停止

```powershell
# 首次使用
npm install        # 安装依赖（已提交lockfile，版本锁定）
npm run build      # 构建前端与后端

# 启动服务（生产方式）
npm start          # http://127.0.0.1:3000 （仅本机可访问）

# 开发模式（前后端热更新）
npm run dev        # 前端 http://localhost:5173 ，/api 代理到3000
```

- 停止：在服务窗口按 `Ctrl+C`。数据已实时落盘，直接停止安全。
- 同一数据目录同时只允许一个服务进程；第二个实例启动会被拒绝。
- 浏览器访问 `http://127.0.0.1:3000`。首次打开自动建立本机会话，无需注册登录。
- 服务只监听127.0.0.1，局域网/公网无法访问；其他网页向本机发起的修改请求会被来源校验拒绝。

## 2. 数据保存在哪里

- 全部数据在项目目录 `data\` 下：`runtime.json`（配置与指针）、`generations\<数据代>\database.sqlite` 与 `attachments\`（数据库与简历附件）、`backups\`（备份）、`staging\`（临时）。
- 数据目录可用环境变量 `APP_DATA_DIR` 重定向；端口用 `APP_PORT`（默认3000）。
- 此目录不入Git、不要手工改动其中文件；备份/恢复请走界面。

## 3. 日常流程速览

家长填模板 → 你粘贴建单 → 导出招募文字发微信群 → 老师按订单编号报名 → 你粘贴报名 → 多选候选生成摘要发家长 → 标已推荐 → 安排一位试课 → 收保证金 → 开始试课 → 通过（确认合作）补齐中介费 → 完成订单；失败/退出/家长取消则退回保证金。

## 4. 粘贴模板自动录入

1. 把空白模板发给家长/老师（首页“家长模板/老师模板”可复制）。
2. 收到填好的整份模板后：
   - 家长：首页 →“粘贴家长模板建单”。
   - 老师：打开对应订单 →“粘贴老师模板报名”；或顶部“粘贴老师报名”（按模板里的订单编号自动定位）。
3. 粘贴原文 → 点“解析并填入表单”。系统按字段名识别（支持中英文冒号、字段顺序变化、别名“微信号/手机号”、多行正文），**解析不写数据库**。
4. 检查解析结果：红色为必须补正项（缺微信/电话、空白占位、薪资区间、相对日期“下周一”等会明确提示，不会乱猜）；黄色为提醒（如“文本提到附件不代表已上传”）。
5. 补正标红项（家长单的“公开区域/公开时间/公开要求”默认要求人工确认，不会照抄详细住址）→ 保存。
6. 保存后原文随记录保存，仅内部可查，随记录一起被90天清理。

注意事项：
- 一次只粘贴一份模板；检测到多份会要求分开粘贴。文本上限5万字符。
- 正文里的括号、冒号、编号会被当作正文保留，不会被误判成新字段。
- 附件：粘贴不等于上传。保存报名后，在报名详情页上传 PDF/JPG/PNG（最多5个、每个10MB）。
- 双击/重试不会重复建记录；同一个人对同一订单再次投递请直接再保存一次（会新建一条报名）。

## 5. 普通表单录入

“新建订单”点“不用粘贴，直接填写”；报名在订单详情点“普通表单报名”。字段与模板一致；家长与老师的微信、电话均必填；老师没有“可授课区域”字段。

## 6. 群内招募文字与候选摘要

- 首页“导出全部招募中文字”：预览全部招募中订单（不受搜索/分页影响），一键复制或下载TXT。只含允许公开的字段（年级/科目/方式/区域/时间/频次/薪资/性别要求/公开要求），不含家长联系方式、详细地址、内部备注。
- 发单前请自行检查公开字段内容（系统不做内容审查）。
- 候选摘要：订单详情勾选多位候选 →“生成候选摘要（发家长）”→ 复制发给家长。摘要按报名编号区分同名老师，不含老师微信/电话/费用/内部备注。**发送后**回来勾选同样的人点“标记已推荐”。
- 费用告知：报名详情“复制费用告知”生成该单的费用说明文字（金额来自你设定的收费），复制≠登记收款。

## 7. 匹配、试课与费用（钱都由老师支付）

每单同时只有一位“当前试课/待结算老师”。

1. **安排试课**：候选详情点“安排试课”（需订单在招募中/挑选中，且没有当前老师）。该报名变为“待试课”并成为当前老师。
2. **设定收费**：报名详情填“中介费”和“计划保证金”（免费个案都填0；计划保证金≤中介费）。开始试课前必须设定。
3. **收保证金**：只在“待试课”状态、且只对当前老师收。可分次登记，累计不超过计划值。
4. **开始试课**：订单详情点“开始试课”（要求保证金收齐）。订单变“试课中”，报名仍是“待试课”。
5. **试课结果**（只能对当前老师登记）：
   - 通过：报名变“试课通过”，订单回到“家长挑选中”，显示“待确认/待结算”。
   - 未通过：不用填原因；清空当前引用，已收款变待退款，可继续挑别人。
6. **确认合作**：试课通过≠确认。双方确认后点“确认合作”（直接跳过试课的合作用“直接合作”按钮，同样要确认后才能补款）。
7. **补款/退款**：确认合作后“登记补收中介费”（不超过待补）；失败/退出/取消后只允许“登记退款”。每笔输入本次实际金额，系统记累计值与最近时间。
8. **更正登记**：录错金额用“更正登记”（必须填理由，展示前后值），不要用假退款来改错。
9. **完成订单**：订单详情“完成订单”。系统自动校验：当前老师已确认合作、成交报名净收=中介费、其他报名净收=0，任一不满足会提示具体差什么。完成后费用锁定，后续授课不在本系统范围。
10. **取消订单**：未完成订单可取消；已收款项不会自动退，需实际退款后逐条登记。

金额一律整数分存储，界面按元显示（最多两位小数）；重复提交由操作ID幂等保护，不会重复加钱。

## 8. 90天自动清理

- 规则：按**最后实际修改**满90天清理；查看/导出/下载不延期，只有真实修改才重新计时。
- 只清理“已完成/已取消”且全部关联报名到期、费用结清/退清的整单；失败/退出报名到期且无待退款、未被引用时可独立删除；在办订单（招募/挑选/待试课/试课/暂停）始终保护。
- 每天00:00后自动评估一次（见维护页显示的上次运行），服务启动时补做；也可在“清理与备份”页预览、手动执行。
- 执行时确有可删数据才先生成“清理前备份”（安全备份，最多10份/30天），备份失败则暂缓删除。
- 删除是永久的（含附件文件）；历史备份不会同步删除。恢复旧备份后系统会重新按90天规则检查。

## 9. 备份与恢复

- **手动备份**：“清理与备份”→“立即备份”，生成完整ZIP（数据库快照+全部附件+清单，含SHA-256校验）。可下载另存到其他磁盘/U盘（防电脑故障，系统不自动上云）。
- **每日自动备份**：每天02:00（香港时间）自动一次；当天启动时若没有当日备份会立即补做；失败5分钟后重试。默认保留最近30份（可在界面调整）。服务停止期间无法备份，不补造历史日期的包。
- **安全备份**：恢复前/清理前自动生成，单独保留最多10份且不超过30天，可在列表下载或手动删除。
- **恢复（界面）**：
  1. “选择备份包（ZIP）”→ 系统校验（格式/清单/校验值/数据库完整性/外键/业务规则/附件齐全）并显示预览（备份时间、数量）。
  2. 点“确认恢复（替换当前数据）”。恢复语义是**替换**到备份时点，备份之后新增/修改的数据会被覆盖；恢复前系统自动备份当前数据（失败则终止，当前数据不受影响）。
  3. 后台自动进入维护状态并原子切换，完成后页面自动回到订单列表。恢复后编号从“本机已发编号与备份编号较大值”之后继续，不会复用已发微信群的编号。
- **恢复（命令行备用）**：先停止服务，再执行
  `npm run restore -- --from <备份ZIP路径> --yes`
- 损坏/缺附件/校验不符/版本不支持的包会被拒绝，当前数据不受影响。
- 自动备份目录可改（默认在数据目录内），但不能与数据目录/附件/暂存目录重合。

## 10. 安全说明

- 仅本机127.0.0.1可访问；跨网页请求、错误Host/来源、缺CSRF令牌的修改请求一律拒绝。
- 附件服务端校验类型与大小（PDF/JPEG/PNG），不按网页渲染用户文件；预览/下载为受控端点。
- 备份包含个人资料，请妥善保管，不要提交Git或外发。

## 11. 常见问题

- **提示“记录已被他人修改，请刷新”**：另一窗口改过这条数据，刷新页面重做即可。
- **提示“页面数据已过期（可能刚完成恢复）”**：刷新页面，系统会自动换新会话。
- **粘贴解析识别不了**：确认粘贴的是系统提供的模板原文；查看“未识别的行”列表，按提示补正；一次只粘贴一份。
- **不能收保证金**：只有“待试课”订单的当前老师可收；先“安排试课”并“设定收费”。
- **不能补款**：确认合作之后才能补款，且不超过待补金额。
- **完成按钮报缺条件**：按提示补——通常是确认合作、补齐中介费、或把其他报名的待退款退清。
