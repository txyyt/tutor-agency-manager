本次只审查需求、规则、技术契约的可执行性与一致性，系统尚未开发，不代表运行测试通过。修正已同步到IMPLEMENTATION_PLAN.md和GOAL_PROMPT.md；后续必须执行AC01—AC61。

| 问题 | 影响 | 修正 |
| --- | --- | --- |
| 通过后仍显示试课中；直接合作当前已选仍可继续招募/暂停 | 阶段错误、可能重复匹配 | 通过回挑选，显示待确认/结算；当前非空时禁止招募/暂停/换人 |
| 非当前候选退出也可能清当前引用 | 丢失真正试课老师 | 仅操作对象等于当前才清引用，状态组合事务校验 |
| 内存财务去重、录错金额缺少更正入口 | 重试重复加钱、伪造退款来改错 | 报名JSON内持久操作ID，带理由更正，不新增费用表 |
| 下调收费后超收与硬性上限冲突 | 合法退款记录不能恢复 | 上限限制新增收款，已发生超收是合法待退款 |
| 备份解锁后才读原附件 | 并发删除使备份缺文件 | 锁内复制整套独立快照，解锁后只打包快照 |
| 清理前全量备份和旧恢复数据代无生命周期 | 磁盘持续增长，删除后原资料仍留旧代 | 空清理不备份，安全备份独立最多10份/30天，成功恢复回收旧代 |
| 恢复/清理嵌套获取维护锁；第二服务实例未限制 | 死锁或并发覆盖 | 外层锁一次、内部持锁方法、数据目录单实例 |
| 恢复后旧页面version可能碰巧相同 | 旧请求覆盖恢复后数据 | 新data_epoch，拒绝旧页面写入，恢复令牌单次使用 |
| 原附件预览未明确；解析忽略说明可能误删正文 | 预览缺失、多行简历损坏 | 明确预览端点/回退、精确模板说明识别和嵌套字段规则 |
| 本机无登录仅监听回环未限制网页来源 | 外部网页可能向本机发修改请求 | Origin/Host与CSRF校验，仍不要求用户账号 |
| 导出体积可超过默认导入上限；备份目录可重叠 | 自己备份不能直接恢复、误轮换业务文件 | 限制可调整并预警，目录隔离，只轮换已登记包 |
| 恢复旧库回退编号序列 | 复用已发微信群编号，报名错单 | 数据代外高水位，恢复后下一号取两者最大值之后 |

仍明确保留的产品边界：本机服务关闭无法定时备份；人工保存的备份不自动去除历史资料；已完成订单财务锁定、不支持后续课程管理；桌面EXE尚未列入必交付范围。这些是当前范围，不是已验证运行缺陷。
